Política de privacidad

rclone-carlos es una aplicación de uso exclusivamente personal. La utiliza solo su propietario para sincronizar sus propios archivos entre su computadora y su propia cuenta de Google Drive, mediante rclone.

Datos a los que accede

La aplicación accede únicamente a los archivos de Google Drive de la cuenta de su propietario, y solo para copiarlos entre esa cuenta y la computadora del propietario.

Uso y almacenamiento

Los datos no se envían a ningún servidor de terceros, no se venden, no se comparten y no se usan para publicidad ni para entrenar modelos. Las credenciales de acceso se guardan solo en la computadora del propietario.

Uso de los datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
